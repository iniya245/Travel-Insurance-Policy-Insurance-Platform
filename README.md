# Travel Insurance Policy Issuance Platform

## Project Overview
The Travel Insurance Policy Issuance Platform is a web application developed using Python Flask and SQLite. It helps users register, log in, apply for travel insurance policies, view their policies, submit insurance claims, and renew policies. It also provides an admin dashboard to manage users and claims.

## Tech Stack
- Frontend: HTML
- Backend: Python Flask
- Database: SQLite
- IDE: Visual Studio Code

## Features
- User Registration
- User Login
- Dashboard
- Apply New Travel Policy
- View My Policies
- Claim Insurance
- Policy Renewal
- Logout
- Admin Login
- Admin Dashboard
- View All Users
- View All Claims

## Local Setup Instructions
1. Install Python.
2. Install Flask.
3. Open the project in Visual Studio Code.
4. Run database.py to create the database.
5. Run app.py.
6. Open http://127.0.0.1:5000 in your browser.
